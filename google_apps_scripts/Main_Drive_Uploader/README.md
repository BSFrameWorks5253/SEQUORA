# ☁️ Main Drive Folder Uploader — Google Apps Script

This Apps Script is designed for **Account 1 (Main Google Drive)** for uploading full folders, master videos, and complete photo archives while preserving local folder and date hierarchies.

---

## 🚀 Quick 3-Step Setup (Takes 1 Minute)

### Step 1: Open Google Apps Script
1. Open your browser and log into your **Main Google Account (Account 1)**.
2. Go to: [https://script.google.com/home/start](https://script.google.com/home/start)
3. Click **+ New Project** (top left) and name it `SEQUORA_Main_Drive_Uploader`.

### Step 2: Paste the Code
1. Open `Code.gs` in the editor:
   - Delete any default code.
   - Copy and paste all the code from [`Code.gs`](file:///d:/ON_GOING%20PROJECT/SEQUORA/google_apps_scripts/Main_Drive_Uploader/Code.gs).
2. Click **+ (Add a file)** next to Files > Select **HTML** > Name it `Index`.
   - Copy and paste all the content from [`Index.html`](file:///d:/ON_GOING%20PROJECT/SEQUORA/google_apps_scripts/Main_Drive_Uploader/Index.html).
3. Click the 💾 **Save** icon.

### Step 3: Deploy as Web App
1. Click the blue **Deploy** button (top right) > **New deployment**.
2. Click the ⚙️ Gear icon next to *Select type* > Choose **Web app**.
3. Configure settings:
   - **Description**: `Main Drive Folder Uploader v1`
   - **Execute as**: `Me (your-main-email@gmail.com)`
   - **Who has access**: `Anyone` (or `Anyone with Google account`)
4. Click **Deploy**.
5. Click **Authorize Access** and accept permissions for your Google Drive.
6. Copy the generated **Web app URL**.

---

## 🎯 How to Use
1. Open the Web App URL in any browser (or inside SEQUORA Studio).
2. Drag and drop any folder or click **Select Folder**.
3. Watch real-time progress as your folder hierarchy is created and all files upload directly into your **Main Google Drive** under `SEQUORA_Master_Archives`!
