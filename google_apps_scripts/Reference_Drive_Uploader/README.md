# 📂 Reference Drive Folder Uploader — Google Apps Script

This Apps Script is designed for **Account 2 (Reference Google Drive)** for high-speed batch uploading of reference photos, `_P`/`_V` thumbnail previews, documents, and catalogs.

---

## 🚀 Quick 3-Step Setup (Takes 1 Minute)

### Step 1: Open Google Apps Script
1. Open your browser and log into your **Reference Google Account (Account 2)**.
2. Go to: [https://script.google.com/home/start](https://script.google.com/home/start)
3. Click **+ New Project** (top left) and name it `SEQUORA_Reference_Drive_Uploader`.

### Step 2: Paste the Code
1. Open `Code.gs` in the editor:
   - Delete any default code.
   - Copy and paste all the code from [`Code.gs`](file:///d:/ON_GOING%20PROJECT/SEQUORA/google_apps_scripts/Reference_Drive_Uploader/Code.gs).
2. Click **+ (Add a file)** next to Files > Select **HTML** > Name it `Index`.
   - Copy and paste all the content from [`Index.html`](file:///d:/ON_GOING%20PROJECT/SEQUORA/google_apps_scripts/Reference_Drive_Uploader/Index.html).
3. Click the 💾 **Save** icon.

### Step 3: Deploy as Web App
1. Click the blue **Deploy** button (top right) > **New deployment**.
2. Click the ⚙️ Gear icon next to *Select type* > Choose **Web app**.
3. Configure settings:
   - **Description**: `Reference Drive Folder Uploader v1`
   - **Execute as**: `Me (your-reference-email@gmail.com)`
   - **Who has access**: `Anyone` (or `Anyone with Google account`)
4. Click **Deploy**.
5. Click **Authorize Access** and accept permissions for your Google Drive.
6. Copy the generated **Web app URL**.

---

## 🎯 How to Use
1. Open the Web App URL in any browser (or inside SEQUORA Studio).
2. Drag and drop any reference folder or click **Select Folder**.
3. All reference files, thumbnails, and preview folders upload directly into your **Reference Google Drive** under `SEQUORA_Reference_Archives`!
